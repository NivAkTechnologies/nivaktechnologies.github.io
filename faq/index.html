01

General

About NivAk Technologies and what we provide.

What does NivAk Technologies do?

NivAk Technologies develops mobile applications, games and digital products, and provides development services including Flutter, Android, Firebase, integrations, monetization and publishing support.

What platforms do you currently develop for?

Our current project services focus on Android and web-based solutions. Available platform options depend on the requirements of each project.

How can I contact NivAk Technologies?

Business and general enquiries can be sent to contact@nivak-technologies.com. Customer and technical support requests can be sent to support@nivak-technologies.com or through our website contact form.

02

Development

Starting, improving and maintaining software projects.

How do I start a development project?

Visit our Services page, choose the service that best matches your project and select Get Started. You can then provide the project title, target platform, current stage, preferred start and project description.

Can you work on an existing app?

Yes. Existing projects can be reviewed for suitable feature development, integrations, bug fixing, maintenance or performance improvements.

Can you add new features to an existing application?

Yes. Our App Feature Development service is intended for adding suitable screens, functionality, workflows and integrations to existing mobile applications.

Do you provide bug fixing and maintenance?

Yes. We can assist with suitable application crashes, UI problems, errors, performance issues and ongoing maintenance requirements.

03

Firebase & Integrations

Backend services and external integrations.

Can you integrate Firebase into an existing app?

Yes. Firebase services can be integrated into suitable existing applications, including Authentication, Cloud Firestore, Storage and related backend features.

Do you provide REST API integration?

Yes. We provide REST API integration for connecting supported mobile applications with external APIs and backend services.

Can you add AI features to an application?

Suitable AI-powered features and external AI services can be integrated depending on the product requirements, technical feasibility and available service APIs.

04

Monetization & Google Play

Advertising, testing and publishing support.

Can you integrate Google AdMob?

Yes. AdMob integration is available for supported mobile applications, including banner, interstitial and rewarded advertising formats.

Do you help with Google Play publishing?

Yes. We provide support with release preparation, store listing setup and production publishing on Google Play.

Can you help with Google Play testing and release preparation?

Yes. Support is available for suitable testing tracks, release setup and preparation for moving an application toward a production release.

05

Projects & Support

Project requests, timing and promotional offers.

What information should I provide for a project request?

Include the project title, target platform, current project stage, preferred start and a clear description of the features, problems or development work required.

How long does a project take?

Project timing depends on the scope, complexity, integrations, existing code, testing requirements and the amount of development work involved. The requirements are reviewed before project timing is discussed.

How do promotional offers work?

Eligible new clients can select a current promotion from the Offers page and submit the project request using the attached promotional code. Offer eligibility is reviewed with the project request before work begins.
