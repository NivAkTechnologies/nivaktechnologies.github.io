Overview

Solve block puzzles, complete levels and progress through colourful adventure worlds.

Block Quest combines classic block-puzzle gameplay with level progression, rewards and themed adventure maps.

Players complete puzzle objectives within limited moves, earn rewards and unlock progress across increasingly challenging levels.

Lives, coins, checkpoints and reward systems add progression while the core puzzle gameplay remains simple to learn and replay.

Privacy & Control

Game data and purchases are handled transparently.

Block Quest stores core game progress locally while selected online services support anonymous authentication, purchase verification, rewarded advertising and other protected game features described in the Privacy Policy.

Read the Block Quest Privacy Policy →
  • Block Quest uses anonymous Firebase authentication for protected online features.
  • Core game progress, settings and gameplay data can be stored locally on the device.
  • Players can access the Block Quest data-deletion information through the website.
  • Google Play purchase tokens may be verified securely through Firebase backend services.
  • Rewarded ads and Google Play purchases are used only for supported game features.
Frequently Asked Questions

Quick answers about Block Quest.

Is Block Quest publicly available?

Block Quest is currently in final development and release preparation.

Does Block Quest require a normal user account?

No traditional sign-up is required. Block Quest can create an anonymous Firebase user identity for protected online services.

Where is game progress stored?

Core game progress and settings can be stored locally on the Android device, while selected protected data such as verified purchase information may be handled through Firebase backend services.

Does Block Quest use rewarded ads?

Yes. Rewarded ads can be used for supported game rewards such as progression-related benefits.

Does Block Quest include purchases?

Yes. Block Quest can offer Google Play in-app purchases for supported coin packs and other game items.
